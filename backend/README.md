# EPICHAT Backend

Backend for the **EPICHAT** application.

## Tech stack

- Node.js
- TypeScript (ESM)
- Express

## Requirements

- Node.js >= 20
- npm

## Install

```bash
npm install
```

## Run (development)

```bash
npm run dev
```

Server runs on:

```
http://localhost:3001
```

## Available routes

### GET /

Returns a simple OK response.

**Response:**

```
OK
```

### GET /epichat

Test route.

**Response:**

```
test test
```
