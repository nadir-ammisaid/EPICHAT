# EPICHAT

Real-time chat application for RTC project - 2026

## Stack

- Frontend: Next.js
- Backend: Node.js (Express)
- Database: PostgreSQL (Prisma)
- Realtime: WebSocket (Socket.IO)

## Installation

```bash
npm install
```

## Run the project

### Backend

```bash
cd backend
npm run dev
```

### Frontend

```bash
cd frontend
npm run dev
```
