# {EPICHAT}

Real-time chat application for RTC project - 2026

## Stack

- Frontend: Next.js
- Backend: Node.js (Express)
- Database: PostgreSQL (Prisma)
- Realtime: WebSocket (Socket.IO)

## Installation

At the root of the project:

```bash
npm install
```

In the backend folder:

```bash
cd backend
npm install
```

In the frontend folder:

```bash
cd frontend
npm install
```

## Run the project

### Backend

```bash
cd backend
npm run dev
```

### Frontend

```bash
cd frontend
npm run dev
```
